
# HIKING CLUB Web

My own design website to be part of responsive design learning. Hiking is one of my favourite activity which always make me excited, so I use it to be my web theme as you can see. As always, this project is part of Full-Stack Engineer course of www.codecademy.com.


## Lessons Learned

* CSS responsive web design
  * min-width & min-height
  * max-width & max-height
* CSS flex-box
  * flex-wrap


## Tech Stack

**Front-end:** HTML, CSS (responsive)
